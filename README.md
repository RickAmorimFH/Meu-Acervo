# 🎬 Meu Acervo

### Um site para baixar vídeos. Só isso mesmo. 😎

Sabe aquele vídeo que você quer guardar para assistir depois? O **Meu Acervo** foi feito para isso: você cola o link, escolhe o formato e baixa o arquivo.

Sem rede social, sem feed infinito, sem tentar virar a próxima grande plataforma da internet. **É só um baixador de vídeos.** 😂

## 🚀 Como funciona?

1. 📋 Copie o link de um vídeo disponível no YouTube.
2. 🔗 Cole no Meu Acervo.
3. 🎥 Escolha **MP4** (vídeo) ou 🎵 **MP3** (áudio).
4. ⬇️ Clique para baixar e pronto!

Também dá para enviar até **10 links por vez**. Porque copiar e colar dez vezes já é exercício suficiente.

## 🛠️ Feito com

- **Python + Flask** — para fazer o site funcionar.
- **yt-dlp** — para obter os arquivos.
- **FFmpeg** — para tratar áudio e vídeo.
- **HTML, CSS e JavaScript** — para tudo ficar apresentável.

## 💻 Rodando no computador

Instale **Python** e **FFmpeg** e siga as instruções de configuração do projeto. No Windows, o arquivo `INICIAR.bat` ajuda a iniciar a aplicação. Dependendo da versão e do site de origem, o `yt-dlp` também pode exigir o **Deno**.

Depois, abra o endereço local indicado no terminal.

> ⚠️ **Importante:** o Meu Acervo serve para baixar conteúdos disponíveis que você tenha direito ou autorização para salvar. Ele **não recupera vídeos apagados**, não acessa vídeos privados e não contorna restrições de acesso.
